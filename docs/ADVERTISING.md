# Advertising and editorial release

All Google advertising defaults to disabled. Manual units exist only after a reviewed article and its tool link. Each of the ten guides lives in the private repository in `lib/editorial/guides.ts`. In the app, sign in with an operator-provisioned administrator account and open **Admin → Editorial review**. Test each draft against the signed-out tool flow, edit its title, summary and sections, and approve the version you reviewed. Saving later drafts leaves the approved copy visible. Withdrawing removes the public copy. The application also requires a second release gate in deployment settings. Set `EDITORIAL_PUBLISHED_SLUGS` to the comma-separated slugs of individual approved articles. Unlisted slugs return 404. Removing a slug withdraws access. Keep all guides private until a founder review.

Before using ads, review the publisher policies, obtain approval for the site and confirm its ownership. Select only articles with enough original content to support useful ad placements. Keep Auto ads disabled in the AdSense account. Hosted user projects, directories, uploads, votes, downloads, checkout, private dashboards and account screens have no ad component.

In the deployment settings set `ADSENSE_APPROVED=true`, `ADSENSE_ENABLED=true`, the actual `ADSENSE_PUBLISHER_ID=pub-<16 digits>`, `ADSENSE_GUIDE_SLOT=<10 digits>` and comma-separated `ADSENSE_REVIEWED_GUIDES`. Enable the separate administrative `adsense_enabled` switch only after configuration. The publisher and slot examples are formats. Use values supplied by AdSense. Visit `/ads.txt` and compare it with the line in your publisher account. This route serves a comment while disabled.

Choose a Google-certified consent management platform integrated with IAB TCF for applicable EEA, UK and Swiss traffic. Determine regional requirements for all target markets and implement opt-out and withdrawal before launch. A custom banner alone does not meet Google's certified CMP requirement. Google documents separate rules for personalized, non-personalized and limited ads. This app's conservative default requests no ads until the CMP explicitly permits the configured use. [Google consent requirements](https://support.google.com/adsense/answer/13554116) · [Ads.txt setup](https://support.google.com/adsense/answer/12171612)

The integration point is `window.loopkitAdConsent`. An operator-installed CMP adapter must implement `mayLoadGoogleAds(): boolean` using actual applicable purposes, vendors and region, and `subscribe(callback): unsubscribe`. Dispatch `loopkit:cmp-ready` once the adapter is available. Missing signals fail closed. On withdrawal, revoke the grant, handle provider cookies using the CMP's procedure and reload the document if required by provider guidance. Do not substitute a hard-coded grant. Verify consent and CSP in each region before enabling either switch. Analytics consent is a separate decision.

Run a fresh browser profile. Inspect network activity before choice, after refusal, after documented consent and after withdrawal. Visit a private route after viewing a guide and confirm no new ad requests. Compare mobile layout while a delayed unit loads. Check the actual publisher console with its supported test procedure. Do not click your own ads. If behavior deviates, disable the database toggle immediately.
