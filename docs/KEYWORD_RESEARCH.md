## Validation worksheet

For each candidate, record the date, country, language, query, example result types, the result that best fits the task, a gap users describe and the matching verified tool action. Sample the US, UK, Canada and Australia. Record Google Trends comparisons as relative interest. After launch, add Search Console clicks, impressions, CTR and average position for the canonical page and country, with the reporting window. Search Console suppresses some queries. Compare equivalent periods and annotate launches or outages before attributing changes. Expand an existing guide when it answers a follow-up question. Create a separate page only for a distinct, supported job.
